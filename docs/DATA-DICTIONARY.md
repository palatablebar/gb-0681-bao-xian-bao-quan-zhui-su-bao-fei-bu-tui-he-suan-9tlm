# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾只隔离该保单，其余保单继续计算。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 日结放行范围

日结时先定范围再付款。行数对账不平则整批HOLD_ALL，不放行任何保单。对账平但某些保单仍有隔离证据（缺失、冲突、引用缺失、版本矛盾）时，只暂缓这些保单，其余按PARTIAL放行；没有隔离证据则RELEASE_ALL。

- 隔离证据按其原始行的policy_id归属保单，整份保单暂缓，暂缓保单的补退金额只作证据，不进入当日划款合计。
- 无法归属到保单的隔离（如列数不齐的短行）不阻断放行，计入未归属隔离。
- 暂缓原因码按行合并（同一行多个原因合并到codes），每行只计一次隔离，保证行数对账仍平。
- 工作台（补退清单、补退对账、结案归档）与结案下载使用同一份settlement范围；结案CSV输出“结算范围/放行/暂缓”记录，暂缓行保留来源行号与原因码，暂缓保单的全部隔离原值保留在“隔离”记录中。
- 同一来源（source）的新内容晚到时，旧批次自动失效：放行范围全部转暂缓并附SUPERSEDED，原范围存入prior_scope留档；旧批次复核返回409 SUPERSEDED，结案下载同样409。新批次重算保持同样的边界与冲突来源。
- 批次血缘键=来源+参数+规则版本，与内容无关；因此源数据晚到变化会生成新批次并取代旧批次，而内容未变的重提不产生新结论。样例批次按样例名，上传批次默认按 `upload:default`，可在提交时用 `source` 指定同源分组。
